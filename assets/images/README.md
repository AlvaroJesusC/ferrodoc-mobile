# Carpeta de Recursos Visuales - Ferretería AYM (ferrodoc_app)

Coloca aquí la imagen del logotipo de tu negocio.

### 📌 Nombre de archivo recomendado:
* **`logo.png`** (o `logo_aym.png`)

### 📐 Especificaciones recomendadas:
* **Formato:** PNG con fondo transparente (o JPG limpio con fondo blanco).
* **Resolución recomendada:** 512x512 px o superior (relación cuadrada o rectangular balanceada).
* **Ubicación exacta:** `assets/images/logo.png`

La aplicación detectará automáticamente si el archivo `logo.png` está presente. Si aún no lo has copiado, la pantalla de inicio (P01 Splash) y el sistema mostrarán de forma automática un logotipo vectorial e insignia de alta calidad de **Ferretería AYM** con la paleta de colores oficial.
